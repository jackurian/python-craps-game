# Craps Game Simulation

A Python-based simulation of the casino game Craps. Designed as a personal project to showcase applied Python skills in a real-world context.

## Features
- Simulates Craps using the random library for dice rolls
- Incorporates pass-line and place bets, and rewards the appropriate payout for each type
- Tracks player balance, starting at 100. Quits the program if balance hits 0
- crapshelp file is imported into the game file (craps.py) to display a reference chart with odds for each roll

## Technologies Used
- Core Python
- Libraries: matplotlib, custom module

## How to Run
- In Terminal: python3 [insert file directory here]/craps.py
